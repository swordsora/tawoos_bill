# Tawoos Invoice PWA

هذا تطبيق فواتير عربي يعمل كـ PWA باستخدام HTML وCSS وJavaScript فقط. يمكن رفع محتويات المجلد إلى GitHub Pages أو Netlify أو أي خادم static يدعم HTTPS. بعد أول فتح، يخزن Service Worker ملفات التطبيق والمنتجات ليعمل التطبيق دون اتصال.

## التشغيل

ارفع جميع الملفات الموجودة في المجلد نفسه، خصوصًا `index.html` و`app.js` و`style.css` و`manifest.json` و`sw.js` و`products.json` و`icon.png`. افتح الرابط في Chrome أو Edge، ثم اختر تثبيت التطبيق من زر التثبيت أو من قائمة المتصفح.

## الوظائف الحالية

يحتوي التطبيق على بيانات 67,502 منتج مستخرجة من جدول الأصناف في قاعدة `tawoos.mdb`. يمكن كتابة أي جزء من اسم المنتج أو كوده داخل نفس الحقل، فتظهر اقتراحات مباشرة. عند الاختيار يظهر الكود وسعرا الجملة والقطاعي، ويمكن تحديد نوع البيع والكمية وإضافة المنتجات وتعديلها أو حذفها. يحسب التطبيق إجمالي الجملة والقطاعي والإجمالي المختار، ويحفظ الفواتير محليًا، ويتيح الطباعة والنسخ الاحتياطي واستيراد المنتجات من JSON أو CSV.

## الاختصارات

`Ctrl+S` لحفظ الفاتورة، `Ctrl+P` للطباعة، `Ctrl+N` لفاتورة جديدة، و`Enter` بعد إدخال الكمية لإضافة المنتج.

## مزامنة الحسابات بين الأجهزة

يوجد داخل مجلد `supabase/schema.sql` مخطط جاهز لجداول الحسابات والعملاء والمنتجات والفواتير. افتح SQL Editor في مشروع Supabase، الصق محتوى الملف وشغّله مرة واحدة. بعد ذلك يحتاج التطبيق إلى عنوان مشروع Supabase ومفتاح anon العام فقط. لا تضع service-role key أو كلمات المرور داخل GitHub. ملف `accounts_manifest.json` يحتوي على 161 حسابًا من MDB بدون قيم كلمات المرور؛ استيراد الحسابات يتم بعد تشغيل المخطط، ثم يعيّن المسؤول كلمات المرور يدويًا للحسابات التي لا يمكن نقل كلمة مرورها بأمان.

## ملاحظة قاعدة البيانات

المتصفح لا يفتح ملف Access MDB مباشرة. لذلك تم تحويل بيانات الأصناف إلى `products.json` داخل التطبيق، مع زر استيراد لتحديث المنتجات من JSON أو CSV لاحقًا. البيانات والفواتير المحفوظة محليًا مرتبطة بالمتصفح والجهاز؛ استخدم زر النسخ الاحتياطي بانتظام.
